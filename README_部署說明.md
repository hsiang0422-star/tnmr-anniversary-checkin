# 臺南特教｜校慶來賓簽到：部署說明

架構：

- **網頁**放在 GitHub Pages（`index.html` 簽到處管理、`view.html` 校長手機查閱）。
- **資料**經 Google Apps Script（`apps-script/`）寫進雲端硬碟的兩份試算表：

| 試算表 | 用途 |
|---|---|
| 臺南特教｜校慶來賓簽到（資料） | 分頁「來賓資料」：程式讀寫的原始資料，**請勿手動改** |
| 臺南特教｜校慶來賓簽到名單 | 分頁「來賓名單」：每次新增／編輯／刪除／排序後自動重寫，可直接列印 |

尚未設定資料 API 時，網頁會以**示範模式**執行（資料只存在該裝置的瀏覽器，示範密碼 `0000`），可先試用畫面。

## 一、建立資料 API（Apps Script，約 5 分鐘）

1. 用 tnmr2301 學校帳號開啟 https://script.google.com →「新專案」，命名「校慶來賓簽到 API」。
2. 把 `apps-script/Code.gs` 整份貼到 `程式碼.gs`。
3. 左側「專案設定」⚙ → 勾選「在編輯器中顯示 appsscript.json」，回到編輯器，把 `apps-script/appsscript.json` 貼上覆蓋。
4. 上方函式選單選 `setup` →「執行」，依畫面完成授權。
5. 下方「執行紀錄」會顯示 **簽到處管理密碼**（6 位數字），請記下來交給簽到處工作人員。
   想改成自己的密碼：在 `setPasscode` 函式裡填入新密碼，執行一次，再把密碼刪掉。
6. 右上「部署」→「新增部署作業」→ 類型「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（GitHub 網頁需要這個設定才能讀寫；新增／修改都要管理密碼）
   若學校網域不允許選「所有人」，請改用 Google Sites 版本。
7. 複製以 `/exec` 結尾的網址。

## 二、把 API 網址接到網頁

打開 GitHub 上的 `config.js` → 按 ✏️ 編輯 → 把網址貼進 `API_URL: ''` 的引號裡 →「Commit changes」。
約 1 分鐘後 GitHub Pages 會更新，示範模式的黃色提示消失就表示已連上試算表。

## 三、兩個入口

- **簽到處管理**：`https://hsiang0422-star.github.io/tnmr-anniversary-checkin/`
  第一次開啟要輸入管理密碼，之後同一台裝置會記住；右上「登出」可清除。
- **校長手機查閱**：`https://hsiang0422-star.github.io/tnmr-anniversary-checkin/view.html`
  不需要密碼，只能看。可做成 QR Code 或加到手機主畫面。

## 四、功能對照

- 輸入姓名（必填）與職稱 → 自動記錄台灣時間，加到名單最後。
- 編輯：只改姓名、職稱，保留原簽到時間與位置。刪除：先顯示來賓姓名確認。
- 上移／下移：每次自動儲存。序號依目前名單從 1 連續編號；刪除後重登的人排最後；清空後從 1 號開始。
- 兩頁都每 4 秒自動更新，順序、序號一致。姓名在前、職稱緊接在後，都是 22 像素，窄螢幕自動換行；時間只顯示「09:15」格式。

## 五、注意

- GitHub 上的程式碼是公開的，但**管理密碼與來賓資料不在 GitHub**：密碼存在 Apps Script 的「指令碼屬性」，名單存在學校雲端硬碟。
- 知道 API 網址的人可以讀到來賓名單（姓名、職稱、時間），但不能修改。
- 10 分鐘內密碼錯誤超過 20 次，管理功能會暫停 10 分鐘。

## 六、修改程式後

- 改 `apps-script/Code.gs`：貼回 Apps Script →「部署」→「管理部署作業」→ ✏️ → 版本「新版本」→「部署」（網址不變）。
- 改網頁檔案：直接在 GitHub 上編輯並 Commit，GitHub Pages 會自動更新。

## 七、校慶結束後清空

打開「（資料）」試算表的「來賓資料」，刪除第 2 列以下的資料，再到 Apps Script 執行一次 `setup`，名單表會一起清空。
