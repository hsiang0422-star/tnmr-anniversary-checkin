# 臺南特教｜校慶來賓簽到：部署說明

整個系統只有一支 Google Apps Script 網頁應用程式（網頁＋資料都在裡面），只允許學校網域帳號使用。

- `apps-script/Code.gs`：後端，讀寫兩份試算表，並提供網頁。
- `apps-script/Index.html`：網頁畫面（簽到處管理、校長手機查閱共用）。
- `apps-script/appsscript.json`：專案設定。

| 試算表 | 用途 |
|---|---|
| 臺南特教｜校慶來賓簽到（資料） | 分頁「來賓資料」：程式讀寫的原始資料，**請勿手動改** |
| 臺南特教｜校慶來賓簽到名單 | 分頁「來賓名單」：每次變動後自動重寫，可直接列印 |

## 一、建立專案（學校帳號，約 5 分鐘）

1. 用 tnmr2301 學校帳號開啟 https://script.google.com →「新專案」，命名「校慶來賓簽到」。
2. 把 `apps-script/Code.gs` 整份貼到 `程式碼.gs`。
3. 「＋」→「HTML」，檔名輸入 `Index`，把 `apps-script/Index.html` 整份貼上。
4. 左側「專案設定」⚙ → 勾選「在編輯器中顯示 appsscript.json」，回到編輯器，把 `apps-script/appsscript.json` 貼上覆蓋，存檔。
5. 上方函式選單選 `setup` →「執行」，依畫面按「審查權限」→ 選學校帳號 →「允許」。
6. 到「執行記錄」找到「簽到處管理密碼：xxxxxx」。

## 二、設定管理密碼

預設密碼是第 6 步產生的 6 位數字。想改成自己的密碼：

1. 左側「專案設定」⚙ →「指令碼屬性」→ 找到 `ADMIN_PASS` → 編輯 → 輸入新密碼（至少 6 碼）→ 儲存。
2. 不需要改程式碼，密碼不會出現在 GitHub 上。

## 三、部署成網頁

1. 右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」。
2. 執行身分：**我**；誰可以存取：**國立臺南特殊教育學校中的所有使用者**。
3. 按「部署」，複製網址（以 `/exec` 結尾）。

之後修改程式：「部署」→「管理部署作業」→ ✏️ → 版本選「新版本」→「部署」，網址不變。

## 四、兩個入口

- **簽到處管理**：`<網址>`，輸入管理密碼後可新增、編輯、刪除、調整順序。
- **校長手機查閱**：`<網址>?page=view`，不需要密碼，只能看。手機用學校帳號登入 Google 後即可開啟，也可以加到主畫面或做成 QR Code。

也可以用 Google Sites 嵌入這兩個網址：「插入」→「嵌入」→「依網址」，選「整頁」。

## 五、功能對照

- 輸入姓名（必填）與職稱 → 自動記錄台灣時間，加到名單最後。
- 編輯：只改姓名、職稱，保留原簽到時間與位置。刪除：先顯示來賓姓名確認。
- 上移／下移：每次自動儲存。序號依目前名單從 1 連續編號；刪除後重登的人排最後；清空後從 1 號開始。
- 兩個頁面都每 4 秒自動更新，順序、序號一致。姓名在前、職稱緊接在後，都是 22 像素，窄螢幕自動換行；時間只顯示「09:15」格式。
- 10 分鐘內密碼錯誤超過 20 次，管理功能會暫停 10 分鐘。

## 六、校慶結束後清空

打開「（資料）」試算表的「來賓資料」，刪除第 2 列以下的資料，再到 Apps Script 執行一次 `setup`，名單表會一起清空。
